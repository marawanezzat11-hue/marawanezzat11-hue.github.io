Home SOC Lab

Objective

Design and implement a functional home SOC environment to simulate real-world security monitoring, log analysis, and threat detection workflows used by SOC analysts.

Architecture

Windows Endpoint → Sysmon & Windows Event Logs → Winlogbeat → Elastic SIEM → Kibana Dashboards & Alerts

Logs Used

  • Windows Security Event Logs (Authentication, Logon/Logoff)
  • Sysmon Process, Network, and File Creation Logs

Detections Implemented

  • Brute-force authentication attempts using repeated failed logons
  • Suspicious PowerShell execution and command-line abuse
  • Unusual process behavior based on Sysmon telemetry

Analyst Responsibilities

  • Monitor SIEM dashboards and alerts
  • Investigate suspicious events and validate true positives
  • Document incidents and detection logic

Outcome

Successfully built a hands-on SOC lab capable of detecting real attack behavior, improving familiarity with SIEM workflows, alert triage, and incident investigation.
