Windows Brute Force Detection

Objective

Detect and alert on brute-force authentication attempts targeting Windows systems to prevent unauthorized access.

Architecture

Windows Security Logs → Winlogbeat → Elastic SIEM → Detection Rules → Alerts

Logs Used

  • Windows Security Event ID 4625 (Failed Logon)
  • Authentication and Logon Events

Detection Logic

  • Multiple failed logins from the same IP within a defined time window
  • High-frequency authentication failures targeting a single user account

MITRE ATT&CK Mapping

  • T1110 – Brute Force

Outcome

Enabled real-time detection of brute-force attacks, allowing rapid alerting and escalation before account compromise.
